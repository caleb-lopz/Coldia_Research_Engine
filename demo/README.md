# Demo Assets

This folder contains safe, redacted examples for demonstrating the research engine.

## Demo scenario

The demo shows how the system can process a fictional product and generate:

- a list of qualified companies,
- outreach strategy recommendations,
- draft cold email and LinkedIn messages,
- and a final PDF report.

## Sensitive data handling

All examples in this folder use placeholder or censored values.
Do not include real customer names, personal emails, private URLs, or confidential business details in demo materials.

## Suggested demo flow

1. Run the pipeline with a sample product description.
2. Review the generated company research and strategy outputs.
3. Open the generated PDF report.
4. Explain the workflow without exposing any sensitive data.
